# Linux 6.6 on the guest-built GCC 9.5 — design and phased plan

Goal: build Linux 6.6 from pinned source inside Tilck/QEMU using stage 20's
GCC 9.5, boot it on QEMU virt and run a static musl /init. This implements
the Linux/QEMU/init design proposed in chat and accepted by “приступаем к линуху”.
BusyBox and native GCC/G++ execution under Linux are included; a full kernel
rebuild under Linux remains a later milestone.

No downloaded executable, host-compiled object, default QEMU OpenSBI or host
build generator enters the ladder. Use the guest-built firmware. The host
may download/hash sources, place bytes and recover guest outputs. Existing
rootfs checkpoints remain the inputs; no repeated run from hex0 is required.
No review subagents or automatic commits/pushes.

## Architecture

Add stage 21-linux with two build rungs, linux-tools and linux-build. The
former starts with rootfs-gcc9.tar and provides bash 4.4, sed 4.8, bison
3.0.4 and bc 1.07.1; existing make 3.82, flex 2.6.4 and binutils 2.30 meet
Linux v6.6's documented minima. The latter builds host utilities natively
inside Tilck, a small static init using musl, and an uncompressed RV64
Linux Image and vmlinux. All Kbuild generators execute inside the guest.

First boot: one hart, serial console, MMU, initramfs, no modules, BTF,
certificates, Rust, networking or disks required. Use the kernel's own
usr/gen_init_cpio to generate an initramfs containing /init and /dev/console.
QEMU gets the Image and cpio bytes, a bootinfo block, and our guest-built
SBI firmware. The Linux loader enters Image at physical 0x80200000 in S
mode with a0=hartid, a1=DTB, satp=0. It must not use Tilck's virtual-address
conversion. SBI TIME/BASE/SRST and legacy console are reused. Keep one
hart until HSM/IPI/RFENCE support is deliberately added.

Alternatives: older Linux reduces build dependencies but is unnecessary
with GCC 9.5; a default QEMU firmware would break the source-only rule.
An updated OpenSBI built in the guest is a fallback only if our existing
SBI lacks a required boot service; never use a prebuilt firmware.
