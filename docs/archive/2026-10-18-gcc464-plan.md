# GCC 4.6.4 на Kronos — поэтапный план

> **Исполнитель:** одна фаза целиком, вместе с её гейтом, потом следующая.
> Коммиты только по явной просьбе в том ходе, где просят. Шагов `git commit` в этом плане нет.
> Прогресс отмечать чекбоксами `- [ ]`.

**Цель:** гостевой `tcc6` собирает GCC 4.6.4 (форк Ekaitz Zárraga, RISC-V + musl) из исходников, и этот `cc1` собирает программу, которая печатает `hello from gcc` в UART.

**Архитектура:** хост не запускает gcc, `configure` и генераторы. Хостовый `kronos.py` только кладёт байты исходников в ramfs. Гость `tcc6` компилирует `.c` в ELF своим ассемблером и линкером (`-nostdlib`, `-Wl,-Ttext=0x10000`, `-Wl,-oformat=elf64-little`, плюс `/lib/crt.s` и `/lib/libc.c`). `cc1` пишет текст GNU as. Пока нет gas, этот текст не запускается.

**Стек:** Kronos в одном QEMU virt, 6G, `python3 -u src/scripts/kronos.py --tcc-self-k`. Успех фазы — подстрока в буфере UART, которую ждёт `handoff_kronos`.

**Стратегия фаз:** risk first. Неизвестное — примет ли tcc 0.9.27 их C и их RISC-V бэкенд. Это проверяется на `version.c` до `cc1`.

| Фаза | Имя | Что появляется |
|------|-----|----------------|
| 1 | Исходник и версия | UART `4.6.4`, затем `gccver464 ok` |
| 2 | Генератор на госте | файл `/src/gcc464/genrtl.h` и UART `gengenrtl464 ok` |
| 3 | `cc1` пишет `hello.s` | файл с настоящей инструкцией и UART `hello.s ok` |
| 4 | hello запускается | UART `hello from gcc` |

**Правило:** гейт фазы k зелёный, прежде чем начинать фазу k+1.

Дальше (musl, пересборка 4.6.4 с C++, апстримный GCC 9.5, Linux, busybox) — отдельный план. Его вход: UART `hello from gcc`.

## Что уже известно про их коммит

Снято с [ekaitz-zarraga/gcc](https://codeberg.org/ekaitz-zarraga/gcc) `c0d20242b1`, без распаковки всего дерева:

- `gcc/version.c` включает только `version.h`. Строка версии не литерал:

```c
const char version_string[] = BASEVER DATESTAMP DEVPHASE REVISION;
const char pkgversion_string[] = PKGVERSION;
const char bug_report_url[] = BUGURL;
```

- `gcc/BASE-VER` — `4.6.4`. `gcc/DATESTAMP` — `20130412`. `gcc/DEV-PHASE` пустой. Файлов `gcc/REVISION` и `BUGURL` в этом коммите нет.
- `gcc/gengenrtl.c` включает `bconfig.h`, `system.h` и как данные `rtl.def`. `main` объявлен как `int main(void)` и пишет в stdout. Флага `-h` у него нет. Легенда дословно:

```c
puts ("/* Generated automatically by gengenrtl from rtl.def.  */\n");
```

- В Kronos `sys_write` на fd 1 и fd 2 уходит в UART (`src/stages/09-kronos/src/syscall.c`). Файл из stdout сам не появится. `stdio.h` не объявляет `freopen`; в `libc.c` есть `freopen_unlocked`.
- `stdlib.h` объявляет `abort`, определения в `libc.c` нет. `gengenrtl.c` зовёт `gcc_unreachable()`, ему нужен `abort`.
- В `libc.c` уже есть `printf`, `puts`, `putchar`, `strcmp`, `strchr`, `ferror`, `fflush`, `fclose`, `stdout`.
- Старые блоки `kmain.c` на `/src/gcc/` и `/src/gcc474/` остаются. Новые файлы сажаются только под `/src/gcc464/` и, в фазе 4, под `/src/binutils/`. `gcc_as_ld` не вызывать и пути `/src/as`, `/src/ld` не сажать.

## Открытость

В KFS этой работы только исходники и короткие заголовки, которые пишет человек, потому что `configure` на хосте запрещён. Запрещены готовый `cc1`, пакет Guix, бинарь Debian, старые `cc1.elf` 4.0.4 и 4.7.4, хостовый прогон `gen*`, подмена `version.c` строкой `puts("4.6.4")`.

```python
def collect_kfs_gcc464():
    root = os.path.join(ROOT, "src", "stages", "12-gcc464")
    tree = os.path.join(root, "artifacts", "tree")
    ents = []
    want = (
        ("gcc/version.c", "/src/gcc464/version.c"),
        ("gcc/version.h", "/src/gcc464/version.h"),
    )
    for src, dest in want:
        path = os.path.join(tree, src)
        if not os.path.isfile(path):
            raise SystemExit("missing %s" % path)
        ents.append((dest, open(path, "rb").read()))
    printver = os.path.join(root, "src", "printver.c")
    ents.append(("/src/gcc464/printver.c", open(printver, "rb").read()))
    for dest, blob in ents:
        print("[gcc464] KFS %s %d" % (dest, len(blob)), flush=True)
    return ents
```

```c
static int gcc464_step(char **compile, const char *bin,
                        char **runav, const char *outfile,
                        const char *needle, const char *ok)
{

    unsigned char *p;
```
