# 01 — hex1

hex1 умеет метки. Им собирают hex2.

**Вход:** `hex1.bin` со стадии 00.  
**Выход:** `hex2.bin`.  
**QEMU:** `do hex1.bin hex2.hex1 hex2.bin`

| На диске | В образе |
|---|---|
| `hex2_riscv64.hex1` | `hex2.hex1` |
| `hello_hex1.hex1` | `testB.hex1` |
