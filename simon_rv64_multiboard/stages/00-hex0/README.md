# 00 — hex0

Самый узкий язык: байты hex + комментарии. Его можно прочитать глазами.

**Вход:** ядро `hex0` (вшито в simon).  
**Выход в образе:** `hex1.bin`.  
**QEMU:** `hex0 hex1.hex0`

| На диске | В образе |
|---|---|
| `hex1_riscv64.hex0` | `hex1.hex0` — исходник hex1 |
| `hello_hex0.hex0` | `testA.hex0` — hello |
